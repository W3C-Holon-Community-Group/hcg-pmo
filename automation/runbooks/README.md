# Runbooks

One runbook per automation, `runbooks/<name>.md`, starting from [`_template.md`](_template.md).

A runbook is written so that **Kurt or Patrick could run the automation without help**, and so that anyone could do the job by hand if the automation is down.

Also here:

- [`access-and-admins.md`](access-and-admins.md): the one page for admin backstops. How to grant or revoke access and who to call.
