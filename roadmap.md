# HCG roadmap

Each quarter, the chairs, team leads and PMO set **3 to 5 group-level goals**. Each goal is a milestone (same name in every repo that carries work for it) and an option in the Project's **Quarter goal** field, so the *Roadmap* view groups work by goal.

Goals say what will be true at the end of the quarter, not a list of activities.

## Template

```markdown
## YYYY QN

Set on YYYY-MM-DD at <meeting>, recorded in decisions/<file>.md

| # | Goal | Done when | Lead | Milestone |
|---|---|---|---|---|
| 1 | | | | [YYYY-QN-short-name](link) |
```

At the end of the quarter, mark each goal **Met**, **Partly met** or **Carried over**, and retire stale items from the board.
